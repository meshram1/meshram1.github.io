Lagrangian Particle Solver for Rocket Flows

Jul 2024 · github.com/meshram1/Lagrangian-Solver-for-Particle-Flow

A Fortran-based solver that solved the straightforward lagrangian equation to determine the particle's location based on EL model on an unstructured grid. The algorithm to find the nearby nodes to the closest node using a Euclidean Distance method and a binary tree data structure (KDTree) is included in the file "nearby_nodes.py". We find the velocity at the particle's current location using weighted linear interpolation from nearby nodes.

Some Results (NASA JPL Nozzle and Boeing's IUS Submerged Nozzle in Thrust-Vectored Configuration respectively).

Context

Research at the Rockets & Missiles Lab, IIT Madras (advisor: Prof. P. A. Ramakrishna), May 2023 to July 2024. The solver tracks unburned propellant particles inside NASA's rocket booster to identify slag-accumulation zones and inform nozzle design, and was optimised to run on AQUA, the HPC cluster at IIT Madras.

Presented at the International Conference on Numerical Methods in Multiphase Flows 5 (ICNMMF-5), Reykjavik, Iceland, June 2024.
